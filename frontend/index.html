About AI Action Recognition

This application uses advanced deep learning to recognize human actions in images. It combines:

  • Convolutional Neural Networks - For accurate action classification
  • LIME (Local Interpretable Model-agnostic Explanations) - For AI explainability
  • FastAPI - For high-performance API backend

The model can recognize 10 different human actions with explanations showing exactly which parts of the image influenced the AI's decision.
